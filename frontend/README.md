# APPsanz&ac · Frontend

SPA en React + Vite + TypeScript + Tailwind que consume la API de `../backend`.

```bash
npm install
cp .env.example .env   # VITE_API_URL (por defecto /api/v1, con proxy a http://127.0.0.1:8000)
npm run dev            # desarrollo
npm run build          # producción -> dist/
```

Consulte el `README.md` de la raíz para la instalación completa y los usuarios de demostración.
